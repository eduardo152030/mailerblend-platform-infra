## 📘 `README.md` — Infra Composable CRM (Budibase + Supabase/Postgres)

```md
# Infra Composable CRM
Budibase + Supabase (PostgreSQL) — Self-Hosted, Composable CRM

Este stack implementa un **CRM operativo, autoalojado y composable**, donde:

- **PostgreSQL (Supabase)** es el *source of truth*
- **Budibase** es únicamente la capa de UI / workflows
- **CouchDB** almacena metadata interna de Budibase (apps, screens, users)
- **Redis** gestiona sesiones y caché
- Sistemas externos (n8n, Lambda, lead-ingest, etc.) **escriben directamente en Postgres vía API**

---

## 🧠 Principios de Arquitectura

- **Single Responsibility**
  - Postgres → datos de negocio
  - Budibase → UI + lógica visual
  - CouchDB → metadata Budibase (NO datos de negocio)
- **Composable**
  - Budibase no “posee” los datos
  - Se puede cambiar la UI sin tocar el modelo
- **Infra first**
  - Todo corre en Docker
  - Acceso y debugging siempre host-level (no dentro de contenedores)

## 🚨 Resolución de Problemas Comunes

### Error:

`Unable to search by SQL - CouchDB error: Not found: /_design/sqlite`

**Causa**
El app fue creado cuando Budibase pensaba que el datasource era SQLite.

**Solución (recomendada)**

* Eliminar el app
* Crear uno nuevo
* Conectar Postgres **antes** de añadir componentes

---

### Error:

`POST /_session: login details rejected`

**Causa**

* CouchDB fue inicializado con otras credenciales
* El volumen ya tenía una contraseña distinta

**Solución**
Reset SOLO Budibase (ver sección anterior).

---

### Budibase aparece `unhealthy` pero la UI responde

Comprobar:

```bash
curl -I http://127.0.0.1:10080/builder
```

Si responde `200` o `301`, **funciona**.
El healthcheck puede ir retrasado.

## 🗄️ Modelo de Datos (Source of Truth)

👉 **Budibase NO crea tablas automáticamente**
👉 **Postgres es el dueño del modelo**

### Crear tablas en Postgres (ejemplo)

```sql
CREATE TABLE companies (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  name text NOT NULL,
  website text,
  created_at timestamptz DEFAULT now()
);

CREATE TABLE leads (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  company_id uuid REFERENCES companies(id),
  email text NOT NULL,
  source text,
  created_at timestamptz DEFAULT now()
);
```

Budibase **consume** estas tablas vía PostgreSQL datasource.

## 🔌 API / Ingestión Externa (n8n, Lambda, lead-ingest)

Patrón recomendado:

```
[ Web / Ads / Forms ]
          |
          v
[ API Gateway / n8n / Lambda ]
          |
          v
[ PostgreSQL (Supabase) ]
          |
          v
[ Budibase UI ]
```

### Ejemplo insert vía API (Postgres)

```sql
INSERT INTO leads (email, source)
VALUES ('lead@example.com', 'landing_page');
```

Budibase refleja el dato automáticamente.
